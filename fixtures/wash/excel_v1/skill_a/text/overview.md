# Quarterly P&L Build

Builds a three-sheet quarterly profit-and-loss workbook with a KPI band on
Summary, a line-item matrix on Details, and a side-by-side bar chart on
Charts. Designed as a structural reference: the agent supplies the
revenue/COGS line items, the formulas and layout come from this skill.

## Applicability

Use whenever the task brief mentions quarterly financial reporting,
revenue/COGS tracking, or YoY comparisons.
