# Support

This repository is released as open-source research software. Please use GitHub
Issues to report bugs, request documentation improvements, or discuss feature
requests.

Before filing a new issue, search existing issues to avoid duplicates. Include
the command you ran, your operating system, Python version, relevant domain, and
the smallest task or input that reproduces the problem.

## Microsoft Support Policy

Support for this project is limited to the resources in this repository and the
GitHub issue tracker. It is not covered by a paid Microsoft support program.
