# Archviz Living Room

Interior architectural-visualisation reference scene: a 5x4-meter living room with Scandinavian furnishings, large window with HDRI sun light, and a hardwood floor with procedural variation. Cycles render setup pre-configured with denoising. Suitable as a starting point for any modern interior scene.
