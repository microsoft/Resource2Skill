### 1. High-level Design Pattern Extraction

> **Skill Name**: Automated PBR Material Setup & Adaptive Displacement

* **Core Visual Mechanism**: Physically Based Rendering (PBR) shading utilizes specific map layers (Base Color, Roughness, Normal, Displacement) properly routed through intermediate nodes (ColorRamp, Invert, Normal Map/Bump, Displacement). It incorporates Cycles-exclusive *Adaptive Subdivision* for genuine micro-displacement that reacts to lighting with physical depth, breaking the flat silhouette of standard geometry.
* **Why Use This Skill (Rationale)**: By separating surface properties into distinct maps, PBR ensures the material reacts accurately and predictably to any lighting condition. Adaptive subdivision dynamically generates geometry detail based on camera proximity, giving you maximum realism without permanently destroying your viewport polygon budget.
* **Overall Applicability**: Essential for architectural visualization, terrain generation, hyper-realistic hard-surface texturing, and adding macro-detail to simple geometry (like brick walls or cobblestone paths) without heavy manual sculpting.
* **Value Addition**: Transforms primitive, flat polygons into incredibly rich, textured, geometrically complex surfaces entirely at render-time. It replaces tedious geometry modeling with procedural shading logic.

### 2. Technical Breakdown

* **Step A: Geometry & Topology**
  - **Base Mesh**: A standard flat Plane primitive.
  - **Modifiers**: A Subdivision Surface Modifier set to `SIMPLE`.
  - **Dicing**: Cycles Adaptive Subdivision (which requires the `EXPERIMENTAL` feature set enabled) divides the mesh dynamically based on screen space, providing enough vertices to physically displace the geometry.
* **Step B: Materials & Shading**
  - **Shader System**: `Principled BSDF`.
  - **Coordinate Mapping**: `Texture Coordinate` (UV) → `Mapping` node network applied uniformly to all maps.
  - **Color**: Procedural Voronoi → `ColorRamp` to map grayscale data to the designated `material_color`.
  - **Roughness**: Noise texture passed through an `Invert` node (simulating the Gloss-to-Roughness conversion taught in the video), then clamped with a `ColorRamp` to control shine.
  - **Normal**: Grayscale noise converted to vector normal data via a `Bump` node.
  - **Displacement**: Voronoi distance passed through a `Displacement` node, plugged directly into the Material Output. Crucially, the material's displacement setting is switched to `DISPLACEMENT_BUMP` (API enum `BOTH`).
* **Step C: Lighting & Rendering Context**
  - **Engine**: Requires the Cycles Render Engine.
  - **Feature Set**: Must be set to `EXPERIMENTAL` to unlock Adaptive Subdivision.
  - **Lighting**: Point lights positioned at shallow angles are recommended to emphasize the physical bumps and self-shadowing generated by the micro-displacement.

### 3. Reproduction Code

#### 3a. Implementation Method Selection

| Aspect of the effect | Method | Why this method |
|---|---|---|
| Base Geometry & Dicing | `bpy.ops.mesh` + Modifiers | Requires a base plane and a Subsurf modifier configured for adaptive dicing. |
| PBR Logic & Node Routing | Shader Node Tree | Procedural replication of the PBR image-texture workflow (Mapping, Inversion, Normal Bump, and Displacement node routing). |
| Engine Configuration | Scene Properties API | Displacement and Adaptive Subsurf are physically disabled unless Cycles Experimental is explicitly turned on via the API. |

> **Feasibility Assessment**: 100% reproduction of the PBR mapping logic. Because external image textures (like Polygon/AmbientCG files) cannot be hardcoded for the agent, the script seamlessly substitutes procedural `Voronoi` and `Noise` textures to feed the exact same PBR network sockets shown in the tutorial. 

#### 3b. Complete Reproduction Code

```python
def create_object(
    scene_name: str = "Scene",
    object_name: str = "PBR_Displaced_Plane",
    location: tuple = (0, 0, 0),
    scale: float = 1.0,
    material_color: tuple = (0.6, 0.2, 0.1),
    **kwargs,
) -> str:
    """
    Create a PBR Material Setup with Adaptive Displacement in the active Blender scene.

    Args:
        scene_name: Name of the target scene.
        object_name: Name for the created object.
        location: (x, y, z) world-space position.
        scale: Uniform scale factor.
        material_color: (R, G, B) base color in 0-1 range.
        **kwargs: Additional overrides.

    Returns:
        Status string.
    """
    import bpy
    from mathutils import Vector

    scene = bpy.data.scenes.get(scene_name) or bpy.context.scene

    # === Step 1: Render Engine Setup ===
    # Displacement requires Cycles and Experimental feature set for Adaptive Subdivision
    scene.render.engine = 'CYCLES'
    scene.cycles.feature_set = 'EXPERIMENTAL'

    # === Step 2: Create Base Geometry ===
    bpy.ops.mesh.primitive_plane_add(size=2, location=location)
    obj = bpy.context.active_object
    obj.name = object_name
    obj.scale = (scale, scale, scale)

    # Add Subdivision Surface Modifier
    subsurf = obj.modifiers.new(name="Subdivision", type='SUBSURF')
    subsurf.subdivision_type = 'SIMPLE'
    subsurf.levels = 6
    subsurf.render_levels = 6
    
    # Enable Adaptive Subdivision if available
    if hasattr(obj.cycles, 'use_adaptive_subdivision'):
        obj.cycles.use_adaptive_subdivision = True

    # === Step 3: Build Material ===
    mat = bpy.data.materials.new(name=f"{object_name}_PBR_Mat")
    mat.use_nodes = True
    
    # Set Displacement Method to 'Displacement and Bump' (enum is 'BOTH')
    if hasattr(mat.cycles, 'displacement_method'):
        mat.cycles.displacement_method = 'BOTH'

    obj.data.materials.append(mat)

    nodes = mat.node_tree.nodes
    links = mat.node_tree.links

    # Clear default nodes
    for node in nodes:
        nodes.remove(node)

    # Output & BSDF Nodes
    out_node = nodes.new(type='ShaderNodeOutputMaterial')
    out_node.location = (1000, 0)

    bsdf_node = nodes.new(type='ShaderNodeBsdfPrincipled')
    bsdf_node.location = (600, 0)
    links.new(bsdf_node.outputs['BSDF'], out_node.inputs['Surface'])

    # Coordinate & Mapping Nodes
    tex_coord = nodes.new(type='ShaderNodeTexCoord')
    tex_coord.location = (-800, 0)

    mapping = nodes.new(type='ShaderNodeMapping')
    mapping.location = (-600, 0)
    links.new(tex_coord.outputs['UV'], mapping.inputs['Vector'])

    # Procedural Color Map
    color_tex = nodes.new(type='ShaderNodeTexVoronoi')
    color_tex.location = (-300, 300)
    color_tex.inputs['Scale'].default_value = 5.0
    links.new(mapping.outputs['Vector'], color_tex.inputs['Vector'])

    color_ramp = nodes.new(type='ShaderNodeValToRGB')
    color_ramp.location = (-50, 300)
    color_ramp.color_ramp.elements[0].color = (0.02, 0.02, 0.02, 1.0)
    color_ramp.color_ramp.elements[1].color = (material_color[0], material_color[1], material_color[2], 1.0)
    links.new(color_tex.outputs['Distance'], color_ramp.inputs['Fac'])
    links.new(color_ramp.outputs['Color'], bsdf_node.inputs['Base Color'])

    # Procedural Roughness Map (mimicking Inverted Gloss from tutorial)
    rough_tex = nodes.new(type='ShaderNodeTexNoise')
    rough_tex.location = (-300, 0)
    rough_tex.inputs['Scale'].default_value = 10.0
    links.new(mapping.outputs['Vector'], rough_tex.inputs['Vector'])

    invert_node = nodes.new(type='ShaderNodeInvert')
    invert_node.location = (-100, 0)
    links.new(rough_tex.outputs['Fac'], invert_node.inputs['Color'])

    rough_ramp = nodes.new(type='ShaderNodeValToRGB')
    rough_ramp.location = (100, 0)
    rough_ramp.color_ramp.elements[0].position = 0.3
    rough_ramp.color_ramp.elements[1].position = 0.8
    links.new(invert_node.outputs['Color'], rough_ramp.inputs['Fac'])
    links.new(rough_ramp.outputs['Color'], bsdf_node.inputs['Roughness'])

    # Procedural Normal Map (using Bump node for grayscale to vector conversion)
    bump_node = nodes.new(type='ShaderNodeBump')
    bump_node.location = (300, -200)
    bump_node.inputs['Strength'].default_value = 0.5
    links.new(rough_tex.outputs['Fac'], bump_node.inputs['Height'])
    links.new(bump_node.outputs['Normal'], bsdf_node.inputs['Normal'])

    # Procedural Displacement Map (The core geometry driver)
    disp_node = nodes.new(type='ShaderNodeDisplacement')
    disp_node.location = (600, -300)
    disp_node.inputs['Scale'].default_value = 0.1
    disp_node.inputs['Midlevel'].default_value = 0.0
    links.new(color_tex.outputs['Distance'], disp_node.inputs['Height'])
    links.new(disp_node.outputs['Displacement'], out_node.inputs['Displacement'])

    return f"Created '{object_name}' with automated procedural PBR material and Cycles adaptive displacement at {location}"
```
