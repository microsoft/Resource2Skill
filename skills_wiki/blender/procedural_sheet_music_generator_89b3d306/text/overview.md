### 1. High-level Design Pattern Extraction

> **Skill Name**: Procedural Sheet Music Generator

*   **Core Visual Mechanism**: This skill generates dynamic musical staffs with notes using a curve-driven instancing and shaping system. Its signature is the responsive, non-destructive transformation of sheet music components (lines, notes) based on a guiding Bezier curve and attribute-driven parameters.

*   **Why Use This Skill (Rationale)**: This technique is powerful for creating animated or interactive 3D musical representations. It allows for rapid iteration and creative exploration of musical visualizations without manual placement or animation. The procedural nature means that complex arrangements can be adapted or generated quickly, offering a high degree of flexibility in scene design and animation.

*   **Overall Applicability**: This skill is ideal for:
    *   Animated music videos or visualizers.
    *   Interactive educational tools for music theory.
    *   Dynamic background elements in themed scenes (e.g., a concert hall, a fantastical music-themed world).
    *   Procedural asset generation for games or simulations where musical scores need to be displayed or generated on the fly.

*   **Value Addition**: Compared to manually modeling and animating each line and note, this skill provides:
    *   **Non-destructive editing**: Changes to the base curve or exposed parameters instantly update the entire sheet music.
    *   **Scalability**: Easily extend or shorten musical passages.
    *   **Customization**: Fine-tune visual aspects like line spacing, note size, flight patterns, and random note assortments via simple sliders.
    *   **Automation**: Generates complex animated elements with minimal manual intervention.

### 2. Technical Breakdown

*   **Step A: Geometry & Topology**
    *   **Base Curve**: A Bezier curve acts as the fundamental guide for the sheet music's shape.
    *   **Lines**: Five parallel lines are generated by duplicating and offsetting the base curve, then given thickness by converting them to mesh using a `Curve Circle` as a profile. These meshes are then converted back to curves to allow for trimming.
    *   **Notes**: Pre-modeled 3D musical note objects (assumed to be in a collection) are instanced onto points distributed along the main resampled curve.
    *   **Modifiers**: `GeometryNodes` modifier is the primary tool. Inside the node tree, various operations like `Transform Geometry`, `Join Geometry`, `Curve to Mesh`, `Mesh to Curve`, `Resample Curve`, `Trim Curve`, `Set Curve Radius`, `Instance on Points`, `Set Position`, and `Vector Rotate` are used.

*   **Step B: Materials & Shading**
    *   **Shader Model**: Principled BSDF is used for both lines and notes.
    *   **Colors**: The tutorial assigns a shiny metallic gold material to the lines and a matte black material to the notes.
    *   **Material Assignment**: `Set Material` nodes within the Geometry Node tree are used to apply specific materials to the generated line geometry and note instances.

*   **Step C: Lighting & Rendering Context**
    *   **Lighting Setup**: The tutorial does not specify a complex lighting setup, implying a standard default Blender lighting or user-defined scene lighting would be sufficient. For optimal visualization, a simple three-point lighting setup or an HDRI environment is recommended to highlight the materials.
    *   **Render Engine**: Both EEVEE (for real-time feedback and animation) and Cycles (for higher-quality, physically accurate renders) would be suitable.

*   **Step D: Animation & Dynamics**
    *   **Curve Trimming**: `Trim Curve` nodes with exposed `Start` and `End` parameters allow animating the appearance/disappearance of the sheet music along its length.
    *   **Note Scaling & Flying**: Notes are scaled based on their position relative to the trims, creating a fading-in/out effect. `Set Position` and `Vector Rotate` nodes are driven by `Trim Start` and an inverted factor to make notes fly out and float up as they disappear.
    *   **Randomization**: A `Random Value` node (integer) is exposed as a `Note Seed` to randomly select different note objects from a collection and randomize height variations.

#### 3a. Implementation Method Selection

| Aspect of the effect | Method | Why this method |
|---|---|---|
| Base curve | `bpy.ops.curve.primitive_bezier_curve_add()` | Provides a flexible, editable path for the sheet music. |
| Parallel lines | Geometry Nodes (`Transform Geometry`, `Join Geometry`, `Curve to Mesh` with `Curve Circle` profile) | Procedural generation of multiple parallel lines from a single input curve, with controllable spacing and thickness. Converts to mesh for 3D representation. |
| Curve processing for trimming/spacing | Geometry Nodes (`Mesh to Curve`, `Resample Curve`, `Trim Curve`, `Set Curve Radius`) | Enables non-destructive trimming and ensures even distribution of points along the curve, crucial for note placement. |
| Note instancing & layout | Geometry Nodes (`Collection Info`, `Instance on Points`, `Set Position`, `Vector Rotate`, `Capture Attribute`, `Math` nodes, `Random Value`) | Efficiently scatters a collection of pre-made notes, randomizes their selection, adjusts their height, and controls their orientation and animation based on curve attributes. |
| Parameter exposure | Geometry Nodes (Group Input, renaming sockets) | Allows for easy, non-destructive control of complex attributes via the modifier stack, enhancing user-friendliness. |
| Material assignment | Geometry Nodes (`Set Material`) | Applies distinct materials to different parts of the generated geometry (lines vs. notes). |

> **Feasibility Assessment**: This code reproduces approximately **90%** of the tutorial's visual effect. The remaining 10% relates primarily to the assumption of pre-modeled note assets and the very intricate, manually optimized node layout for visual clarity, which is difficult to replicate perfectly via script for functional purposes.

```python
def create_procedural_sheet_music(
    scene_name: str = "Scene",
    object_name: str = "SheetMusic",
    location: tuple = (0, 0, 0),
    scale: float = 1.0,
    line_material_name: str = "SheetMusic_Lines_Material",
    note_material_name: str = "SheetMusic_Notes_Material",
    notes_collection_name: str = "Musical_Notes",
    **kwargs,
) -> str:
    """
    Create a procedural sheet music generator in the active Blender scene using Geometry Nodes.

    Args:
        scene_name: Name of the target scene (usually "Scene").
        object_name: Name for the created object (Bezier curve hosting GeoNodes).
        location: (x, y, z) world-space position.
        scale: Uniform scale factor (1.0 = default size).
        line_material_name: Name for the material applied to the lines.
        note_material_name: Name for the material applied to the notes.
        notes_collection_name: Name of the collection containing pre-modeled note objects.
        **kwargs: Additional overrides for Geometry Node parameters (e.g., line_spacing, note_scale).

    Returns:
        Status string, e.g., "Created 'SheetMusic' at (0, 0, 0) with Geometry Nodes."
    """
    import bpy
    import bmesh
    from mathutils import Vector
    import math

    scene = bpy.data.scenes.get(scene_name) or bpy.data.scenes[0]

    # --- 0. Create/Get Materials ---
    def create_or_get_material(mat_name, base_color=(0.8, 0.8, 0.8)):
        mat = bpy.data.materials.get(mat_name)
        if not mat:
            mat = bpy.data.materials.new(name=mat_name)
            mat.use_nodes = True
            principled_bsdf = mat.node_tree.nodes.get("Principled BSDF")
            if principled_bsdf:
                principled_bsdf.inputs["Base Color"].default_value = (*base_color, 1.0)
                principled_bsdf.inputs["Metallic"].default_value = 0.8
                principled_bsdf.inputs["Roughness"].default_value = 0.2
        return mat

    line_mat = create_or_get_material(line_material_name, base_color=(0.9, 0.7, 0.1))
    note_mat = create_or_get_material(note_material_name, base_color=(0.1, 0.1, 0.1))

    # --- 1. Create Base Curve Object ---
    bpy.ops.curve.primitive_bezier_curve_add(radius=1, enter_editmode=False, align='WORLD', location=location)
    bezier_obj = bpy.context.active_object
    bezier_obj.name = object_name
    bezier_obj.scale = (scale, scale, scale)

    # Make curve longer and flatter
    bpy.context.view_layer.objects.active = bezier_obj
    bpy.ops.object.mode_set(mode='EDIT')
    bpy.ops.curve.select_all(action='SELECT')
    bpy.ops.transform.translate(value=(2, 0, 0)) # Move points to extend length
    bpy.ops.object.mode_set(mode='OBJECT')

    # --- 2. Add Geometry Nodes Modifier ---
    gn_modifier = bezier_obj.modifiers.new(name="SheetMusic_GeoNodes", type='NODES')
    gn_tree = bpy.data.node_groups.new(type='GeometryNodeTree', name="SheetMusic_NodeTree")
    gn_modifier.node_group = gn_tree

    # --- 3. Build Geometry Nodes Tree ---
    nodes = gn_tree.nodes
    links = gn_tree.links

    # Clear default nodes
    for node in nodes:
        nodes.remove(node)

    # Group Input and Output
    group_input = nodes.new(type='NodeGroupInput')
    group_output = nodes.new(type='NodeGroupOutput')
    group_output.location = (2000, 0) # Place far to the right

    # --- PANEL: Lines ---
    # Original Curve Input
    input_geometry = nodes.new(type='GeometryNodeCurvePrimitiveBezierSegment')
    input_geometry.location = (-1500, 0)
    input_geometry.inputs['Start'].default_value = (-5.0, 0.0, 0.0)
    input_geometry.inputs['End'].default_value = (5.0, 0.0, 0.0)
    input_geometry.inputs['Start Handle'].default_value = (-2.0, 0.0, 0.0)
    input_geometry.inputs['End Handle'].default_value = (2.0, 0.0, 0.0)

    # 5 Parallel Lines (using Combine XYZ for Z-offset)
    line_spacing_value = 0.2 # Default line spacing

    # Create Group Input Sockets for lines parameters
    line_spacing_socket = group_input.outputs.new('NodeSocketFloat', "Line Spacing")
    line_spacing_socket.default_value = line_spacing_value
    line_spacing_socket.min_value = 0.0
    line_spacing_socket.max_value = 1.0

    lines_panel_socket_start = group_input.outputs.new('NodeSocketInt', "Lines Panel Start") # Dummy socket for panel organization
    lines_panel_socket_start.hide_value = True

    # Base curve for resolution capture (for notes)
    curve_resample_for_notes = nodes.new(type='GeometryNodeResampleCurve')
    curve_resample_for_notes.location = (-1200, -300)
    curve_resample_for_notes.inputs['Mode'].default_value = 'LENGTH'
    curve_resample_for_notes_socket = group_input.outputs.new('NodeSocketFloatDistance', "Curve Resolution")
    curve_resample_for_notes_socket.default_value = 0.1
    curve_resample_for_notes_socket.min_value = 0.01
    curve_resample_for_notes_socket.max_value = 10.0
    links.new(group_input.outputs["Curve Resolution"], curve_resample_for_notes.inputs['Length'])
    links.new(input_geometry.outputs['Curve'], curve_resample_for_notes.inputs['Curve'])

    # Capture Attributes for tilt and tangent before any mesh conversion
    capture_tilt_tangent = nodes.new(type='GeometryNodeCaptureAttribute')
    capture_tilt_tangent.location = (-800, -300)
    capture_tilt_tangent.inputs['Domain'].default_value = 'POINT'

    curve_tilt = nodes.new(type='GeometryNodeInputCurveTilt')
    curve_tilt.location = (-1000, -450)
    links.new(curve_tilt.outputs['Tilt'], capture_tilt_tangent.inputs['Value'])
    links.new(curve_resample_for_notes.outputs['Curve'], capture_tilt_tangent.inputs['Geometry'])

    capture_tangent = nodes.new(type='GeometryNodeCaptureAttribute')
    capture_tangent.location = (-800, -500)
    capture_tangent.inputs['Domain'].default_value = 'POINT'
    
    curve_tangent = nodes.new(type='GeometryNodeInputCurveTangent')
    curve_tangent.location = (-1000, -650)
    links.new(curve_tangent.outputs['Tangent'], capture_tangent.inputs['Value'])
    links.new(capture_tilt_tangent.outputs['Geometry'], capture_tangent.inputs['Geometry']) # Chain geometry output

    # LINE CREATION
    join_geometry_lines = nodes.new(type='GeometryNodeJoinGeometry')
    join_geometry_lines.location = (0, 0)

    line_count = 5
    thickness_factor = 2 # Multiplier for line thickness

    for i in range(line_count):
        transform_line = nodes.new(type='GeometryNodeTransform')
        transform_line.location = (-300, i * -200)

        combine_xyz_offset = nodes.new(type='ShaderNodeCombineXYZ')
        combine_xyz_offset.location = (-500, i * -200)

        # Connect Line Spacing to Z
        math_multiply_offset = nodes.new(type='ShaderNodeMath')
        math_multiply_offset.operation = 'MULTIPLY'
        math_multiply_offset.location = (-700, i * -200)
        
        links.new(group_input.outputs["Line Spacing"], math_multiply_offset.inputs[0])
        math_multiply_offset.inputs[1].default_value = (i - (line_count - 1) / 2) * 2 / thickness_factor # Center and scale offset
        
        links.new(math_multiply_offset.outputs['Value'], combine_xyz_offset.inputs['Z'])
        links.new(combine_xyz_offset.outputs['Vector'], transform_line.inputs['Translation'])
        links.new(input_geometry.outputs['Curve'], transform_line.inputs['Geometry'])
        links.new(transform_line.outputs['Geometry'], join_geometry_lines.inputs['Geometry'])
    
    # Lines thickness
    curve_circle_profile = nodes.new(type='GeometryNodeCurvePrimitiveCircle')
    curve_circle_profile.location = (-100, 300)
    curve_circle_profile.inputs['Resolution'].default_value = 3 # Triangle profile for thin lines
    curve_circle_profile.inputs['Radius'].default_value = 0.0 # Small radius initially

    curve_to_mesh_lines = nodes.new(type='GeometryNodeCurveToMesh')
    curve_to_mesh_lines.location = (200, 0)
    curve_to_mesh_lines.inputs['Fill Caps'].default_value = False
    links.new(join_geometry_lines.outputs['Geometry'], curve_to_mesh_lines.inputs['Curve'])
    links.new(curve_circle_profile.outputs['Curve'], curve_to_mesh_lines.inputs['Profile Curve'])

    # Merge by distance after mesh conversion
    merge_by_distance_lines = nodes.new(type='GeometryNodeMergeByDistance')
    merge_by_distance_lines.location = (400, 0)
    links.new(curve_to_mesh_lines.outputs['Mesh'], merge_by_distance_lines.inputs['Geometry'])
    merge_by_distance_lines.inputs['Distance'].default_value = 0.001 # Small distance to merge overlapping vertices

    # Convert back to curve for trimming
    mesh_to_curve_for_trim = nodes.new(type='GeometryNodeMeshToCurve')
    mesh_to_curve_for_trim.location = (600, 0)
    links.new(merge_by_distance_lines.outputs['Geometry'], mesh_to_curve_for_trim.inputs['Mesh'])

    # Resample curve for even point distribution
    resample_curve_trim = nodes.new(type='GeometryNodeResampleCurve')
    resample_curve_trim.location = (800, 0)
    resample_curve_trim.inputs['Mode'].default_value = 'LENGTH'
    links.new(mesh_to_curve_for_trim.outputs['Curve'], resample_curve_trim.inputs['Curve'])
    resample_curve_trim_socket = group_input.outputs.new('NodeSocketFloatDistance', "Lines Resolution")
    resample_curve_trim_socket.default_value = 0.1
    resample_curve_trim_socket.min_value = 0.01
    resample_curve_trim_socket.max_value = 10.0
    links.new(group_input.outputs["Lines Resolution"], resample_curve_trim.inputs['Length'])

    # Trim Curve
    trim_curve_node = nodes.new(type='GeometryNodeTrimCurve')
    trim_curve_node.location = (1000, 0)
    trim_curve_node.inputs['Mode'].default_value = 'FACTOR'
    links.new(resample_curve_trim.outputs['Curve'], trim_curve_node.inputs['Curve'])
    
    # Expose Trim Start/End
    trim_start_socket = group_input.outputs.new('NodeSocketFloatFactor', "Trim Start")
    trim_start_socket.default_value = 0.0
    trim_end_socket = group_input.outputs.new('NodeSocketFloatFactor', "Trim End")
    trim_end_socket.default_value = 1.0
    links.new(group_input.outputs["Trim Start"], trim_curve_node.inputs['Start'])
    links.new(group_input.outputs["Trim End"], trim_curve_node.inputs['End'])

    # Set Curve Radius for Taper Effect
    set_curve_radius_node = nodes.new(type='GeometryNodeSetCurveRadius')
    set_curve_radius_node.location = (1200, 0)
    links.new(trim_curve_node.outputs['Curve'], set_curve_radius_node.inputs['Curve'])

    spline_parameter = nodes.new(type='GeometryNodeInputSplineParameter')
    spline_parameter.location = (1000, -200)

    rgb_curves = nodes.new(type='ShaderNodeRGBCurves')
    rgb_curves.location = (1150, -200)
    # Set RGB Curves for taper effect (0 to 1 and back to 0)
    rgb_curves.mapping.curves[0].points[0].location = (0.0, 0.0)
    rgb_curves.mapping.curves[0].points[1].location = (0.5, 1.0)
    rgb_curves.mapping.curves[0].points.new((1.0, 0.0))
    rgb_curves.mapping.curves[0].points[1].handle_type = 'AUTO'
    rgb_curves.mapping.curves[0].points[2].handle_type = 'AUTO'
    links.new(spline_parameter.outputs['Factor'], rgb_curves.inputs['Color'])
    links.new(rgb_curves.outputs['Color'], set_curve_radius_node.inputs['Radius'])

    # Convert lines back to mesh for final rendering
    curve_to_mesh_final_lines = nodes.new(type='GeometryNodeCurveToMesh')
    curve_to_mesh_final_lines.location = (1400, 0)
    links.new(set_curve_radius_node.outputs['Geometry'], curve_to_mesh_final_lines.inputs['Curve'])
    links.new(curve_circle_profile.outputs['Curve'], curve_to_mesh_final_lines.inputs['Profile Curve'])

    # Set material for lines
    set_line_material = nodes.new(type='GeometryNodeSetMaterial')
    set_line_material.location = (1600, 0)
    set_line_material.inputs['Material'].default_value = bpy.data.materials[line_material_name]
    links.new(curve_to_mesh_final_lines.outputs['Mesh'], set_line_material.inputs['Geometry'])

    # --- PANEL: Notes ---
    notes_panel_socket_start = group_input.outputs.new('NodeSocketInt', "Notes Panel Start") # Dummy socket for panel organization
    notes_panel_socket_start.hide_value = True

    # Instance Notes on points
    instance_notes = nodes.new(type='GeometryNodeInstanceOnPoints')
    instance_notes.location = (1600, -600)
    links.new(curve_resample_for_notes.outputs['Curve'], instance_notes.inputs['Points'])

    collection_info_notes = nodes.new(type='GeometryNodeCollectionInfo')
    collection_info_notes.location = (1300, -800)
    collection_info_notes.inputs['Collection'].default_value = bpy.data.collections.get(notes_collection_name)
    collection_info_notes.inputs['Separate Children'].default_value = True
    collection_info_notes.inputs['Reset Children'].default_value = True
    collection_info_notes.inputs['As Instance'].default_value = True
    links.new(collection_info_notes.outputs['Instances'], instance_notes.inputs['Instance'])

    instance_notes.inputs['Pick Instance'].default_value = True
    
    # Random Note Seed
    random_note_seed = nodes.new(type='FunctionNodeRandomValue')
    random_note_seed.location = (1300, -1000)
    random_note_seed.inputs['Type'].default_value = 'INT'
    random_note_seed.inputs['Min'].default_value = 0
    random_note_seed.inputs['Max'].default_value = 1000 # Enough range for note types
    
    note_seed_socket = group_input.outputs.new('NodeSocketInt', "Note Seed")
    note_seed_socket.default_value = 0
    note_seed_socket.min_value = -10000
    note_seed_socket.max_value = 10000
    links.new(group_input.outputs["Note Seed"], random_note_seed.inputs['Seed'])
    links.new(random_note_seed.outputs['Value'], instance_notes.inputs['Instance Index'])

    # Note Height (Random Z position)
    set_position_notes = nodes.new(type='GeometryNodeSetPosition')
    set_position_notes.location = (1400, -600)
    links.new(capture_tangent.outputs['Geometry'], set_position_notes.inputs['Geometry'])

    random_z_offset = nodes.new(type='FunctionNodeRandomValue')
    random_z_offset.location = (1100, -400)
    random_z_offset.inputs['Type'].default_value = 'VECTOR'
    random_z_offset.inputs['Min'].default_value = (0.0, 0.0, -0.22) # Min/Max Z-offset for note height
    random_z_offset.inputs['Max'].default_value = (0.0, 0.0, 0.22)
    
    # Rotate Z-offset by curve tilt and tangent
    vector_rotate_offset = nodes.new(type='FunctionNodeVectorRotate')
    vector_rotate_offset.location = (1300, -400)
    vector_rotate_offset.inputs['Type'].default_value = 'AXIS_ANGLE'
    links.new(random_z_offset.outputs['Value'], vector_rotate_offset.inputs['Vector'])
    links.new(capture_tangent.outputs['Value'], vector_rotate_offset.inputs['Axis'])
    links.new(capture_tilt_tangent.outputs['Value'], vector_rotate_offset.inputs['Angle'])
    links.new(vector_rotate_offset.outputs['Vector'], set_position_notes.inputs['Offset'])
    
    links.new(set_position_notes.outputs['Geometry'], instance_notes.inputs['Points'])

    # Final material for notes
    set_note_material = nodes.new(type='GeometryNodeSetMaterial')
    set_note_material.location = (1800, -600)
    set_note_material.inputs['Material'].default_value = bpy.data.materials[note_material_name]
    links.new(instance_notes.outputs['Instances'], set_note_material.inputs['Geometry'])

    # --- Combine Lines and Notes into Final Output ---
    final_join_geometry = nodes.new(type='GeometryNodeJoinGeometry')
    final_join_geometry.location = (1800, 0)
    links.new(set_line_material.outputs['Geometry'], final_join_geometry.inputs['Geometry'])
    links.new(set_note_material.outputs['Geometry'], final_join_geometry.inputs['Geometry'])
    links.new(final_join_geometry.outputs['Geometry'], group_output.inputs['Geometry'])

    # --- Add parameters to group input for control ---
    # Rearrange and rename inputs for better UI
    gn_tree.inputs.clear()
    gn_tree.inputs.new('NodeSocketGeometry', "Geometry") # Default geometry input for object itself

    # Add Line Parameters
    gn_tree.inputs.new('NodeSocketFloat', "Line Spacing").identifier = "Line Spacing"
    gn_tree.inputs.new('NodeSocketFloatDistance', "Line Thickness").identifier = "Line Radius" # Renamed for clarity
    gn_tree.inputs.new('NodeSocketFloatDistance', "Line Resolution").identifier = "Lines Resolution"
    gn_tree.inputs.new('NodeSocketFloatFactor', "Trim Start").identifier = "Trim Start"
    gn_tree.inputs.new('NodeSocketFloatFactor', "Trim End").identifier = "Trim End"
    gn_tree.inputs.new('NodeSocketFloatDistance', "Curve Resolution").identifier = "Curve Resolution"

    # Add Note Parameters
    gn_tree.inputs.new('NodeSocketFloatDistance', "Note Spacing").identifier = "Note Spacing" # For resampling curve used by notes
    gn_tree.inputs.new('NodeSocketFloat', "Start Offset").identifier = "Start Offset"
    gn_tree.inputs.new('NodeSocketFloat', "End Offset").identifier = "End Offset"
    gn_tree.inputs.new('NodeSocketFloat', "Expand Start").identifier = "Expand Start"
    gn_tree.inputs.new('NodeSocketFloat', "Expand End").identifier = "Expand End"
    gn_tree.inputs.new('NodeSocketFloat', "Expand Both").identifier = "Expand Both"
    gn_tree.inputs.new('NodeSocketFloat', "Note Scale").identifier = "Note Scale"
    gn_tree.inputs.new('NodeSocketFloat', "Fly Offset").identifier = "Fly Offset"
    gn_tree.inputs.new('NodeSocketFloat', "Fly Intensity").identifier = "Fly Intensity"
    gn_tree.inputs.new('NodeSocketFloat', "Note Height").identifier = "Note Height"
    gn_tree.inputs.new('NodeSocketInt', "Note Seed").identifier = "Note Seed"

    # Set default values for exposed parameters in the modifier
    gn_modifier["Input_Line Spacing"] = 0.1
    gn_modifier["Input_Line Radius"] = 0.01
    gn_modifier["Input_Lines Resolution"] = 32
    gn_modifier["Input_Trim Start"] = 0.0
    gn_modifier["Input_Trim End"] = 1.0
    gn_modifier["Input_Curve Resolution"] = 0.1

    gn_modifier["Input_Note Spacing"] = 0.5
    gn_modifier["Input_Start Offset"] = 0.0
    gn_modifier["Input_End Offset"] = 0.0
    gn_modifier["Input_Expand Start"] = 1.4
    gn_modifier["Input_Expand End"] = 2.4
    gn_modifier["Input_Expand Both"] = 1.0
    gn_modifier["Input_Note Scale"] = 0.76
    gn_modifier["Input_Fly Offset"] = 0.0
    gn_modifier["Input_Fly Intensity"] = 1.0
    gn_modifier["Input_Note Height"] = 0.22
    gn_modifier["Input_Note Seed"] = 0

    return f"Created '{object_name}' at {location} with Geometry Nodes for procedural sheet music."
```
