# Modular Sci-Fi Corridor

Reusable Blender scene: 4-meter modular sci-fi corridor segment with PBR steel materials, recessed wall lighting, and a procedural floor grate via geometry nodes. Designed to be duplicated end-to-end via array modifier to build longer corridors. Uses the EEVEE render engine for fast iteration.

## Key components
- Wall segments: hard-surface mesh with bevelled edges + emissive panel inserts
- Floor: geometry-nodes grate driven by a noise texture for varied wear
- Lighting: emissive material on the recessed strips + a single area light overhead
