### 1. High-level Design Pattern Extraction

> **Skill Name**: Generative MIDI Capture Routing (Baking MIDI from Plugins)

* **Core Musical Mechanism**: Capturing and "baking" the MIDI output of generative plugins (like arpeggiators, chord sequencers, or the Reason Rack "Players" shown in the video) directly into track media items. This is achieved through two distinct REAPER routing techniques: using the **Input FX Chain** or switching the recording mode to **Record: output (MIDI)**.
* **Why Use This Skill (Rationale)**: Generative MIDI tools (like Cthulhu, Scaler, or Reason Bassline Generator) create complex musical patterns from simple input triggers (e.g., holding a single C note generates a full bassline). If you record normally, REAPER only captures your single trigger note. By routing the track to capture the *output* of the generator, you print the actual complex sequence into a MIDI item, allowing you to edit, nudge, or alter individual notes of the generated performance later.
* **Overall Applicability**: Essential for producers using MIDI sequencers, algorithmic beat generators, or chord trigger plugins who want full manual control over the generated composition before the final mixdown.
* **Value Addition**: Transforms a track from a standard "instrument player" into a "MIDI capture" utility. It encodes REAPER's specific signal flow knowledge, distinguishing between pre-record processing (Input FX) and post-record processing (Standard FX).

### 2. Technical Breakdown

The video demonstrates the workflow of placing a generative MIDI plugin (Reason Rack Player) before a synthesizer (Massive X) to generate and record a bassline. Because third-party plugins cannot be guaranteed, this breakdown translates the core REAPER routing into a universal, stock-plugin equivalent.

* **Step A: The Input FX Method (Shown at 0:33)**
  - Plugins placed in the `IN FX` (Input FX) chain process the incoming MIDI *before* it reaches REAPER's recording mechanism.
  - Standard `Record: Input` mode will naturally capture the generated notes.
  - The actual sound generator (Synth) must be placed in the standard `FX` chain so it doesn't get recorded as audio.

* **Step B: The Record Output Method (Shown at 1:13 & 1:36)**
  - Plugins placed in the standard `FX` chain process MIDI *after* the recording stage.
  - To capture their output, the track's record mode must be explicitly changed to `Record: output -> Record: output (MIDI)` (Internal REAPER API value `I_RECMODE = 4`).
  - The MIDI generator must be positioned *before* the synthesizer in the FX chain.

* **Step C: Sound Design & FX Setup**
  - **MIDI Generator**: Reason Rack Bassline Generator (reproducible with `JS: MIDI Arpeggiator` or `JS: MIDI Chords`).
  - **Instrument**: Native Instruments Massive X (reproducible with `VSTi: ReaSynth`).

```python
def create_pattern(
    project_name: str = "MyProject",
    **kwargs
) -> str:
    """
    Creates two track templates demonstrating how to capture/record MIDI 
    generated by VST plugins (arpeggiators, chord generators) in REAPER.
    """
    import reaper_python as RPR

    # MIDI Input calculation: 4096 (Base MIDI) + (63 (All Devices) * 32) + 0 (All Channels) = 6112
    MIDI_ALL_INPUTS = 6112

    # =====================================================================
    # METHOD 1: The Input FX Method (From video timestamp 0:33)
    # =====================================================================
    track_idx_1 = RPR.RPR_CountTracks(0)
    RPR.RPR_InsertTrackAtIndex(track_idx_1, True)
    track_1 = RPR.RPR_GetTrack(0, track_idx_1)
    RPR.RPR_GetSetMediaTrackInfo_String(track_1, "P_NAME", "1. Input FX Gen (Rec Input)", True)

    # 1. Add Generative MIDI plugin to the INPUT FX chain (recFX = True)
    RPR.RPR_TrackFX_AddByName(track_1, "JS: MIDI Arpeggiator", True, -1)
    
    # 2. Add Instrument to the STANDARD FX chain (recFX = False)
    RPR.RPR_TrackFX_AddByName(track_1, "VSTi: ReaSynth", False, -1)

    # 3. Setup Recording: Arm track, Set Input to MIDI All, Set Mode to Record Input (0)
    RPR.RPR_SetMediaTrackInfo_Value(track_1, "I_RECARM", 1)
    RPR.RPR_SetMediaTrackInfo_Value(track_1, "I_RECINPUT", MIDI_ALL_INPUTS)
    RPR.RPR_SetMediaTrackInfo_Value(track_1, "I_RECMODE", 0) 


    # =====================================================================
    # METHOD 2: The Record Output Method (From video timestamp 1:13)
    # =====================================================================
    track_idx_2 = RPR.RPR_CountTracks(0)
    RPR.RPR_InsertTrackAtIndex(track_idx_2, True)
    track_2 = RPR.RPR_GetTrack(0, track_idx_2)
    RPR.RPR_GetSetMediaTrackInfo_String(track_2, "P_NAME", "2. Main FX Gen (Rec Output MIDI)", True)

    # 1. Add Generative MIDI plugin to the STANDARD FX chain (recFX = False)
    RPR.RPR_TrackFX_AddByName(track_2, "JS: MIDI Chords", False, -1)
    
    # 2. Add Instrument AFTER the MIDI generator in the STANDARD FX chain
    RPR.RPR_TrackFX_AddByName(track_2, "VSTi: ReaSynth", False, -1)

    # 3. Setup Recording: Arm track, Set Input to MIDI All, Set Mode to Record Output MIDI (4)
    RPR.RPR_SetMediaTrackInfo_Value(track_2, "I_RECARM", 1)
    RPR.RPR_SetMediaTrackInfo_Value(track_2, "I_RECINPUT", MIDI_ALL_INPUTS)
    RPR.RPR_SetMediaTrackInfo_Value(track_2, "I_RECMODE", 4)

    return "Created 2 tracking templates for generative MIDI capture (Input FX routing vs Record Output MIDI routing)."
```
