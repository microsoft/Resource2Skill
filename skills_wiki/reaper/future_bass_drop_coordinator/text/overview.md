# Future Bass Drop Coordinator

Creates a 48-bar future-bass structure in one coherent project context:
airy intro pad plus vocal-like stabs, rising build and snare roll, main drop
with half-time trap drums, 808 sub, sidechained pad, and detuned supersaw
lead, then breakdown and final octave-doubled drop.

Use this before detail skills for Flume / Illenium / San Holo style briefs.
It uses the project-native `Track` and dictionary-note API, so it executes
inside the headless Reaper MCP server without relying on unavailable helpers.
