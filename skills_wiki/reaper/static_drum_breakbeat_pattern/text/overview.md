# Drum Breakbeat Pattern

Two-bar MIDI breakbeat pattern in 4/4 at 90 BPM, single track. Pattern: classic Amen-style break — kick on beats 1+3, snare on 2+4 with ghost notes, syncopated hi-hat 16ths, and crash on the downbeat of bar 2. Pitched on GM drum channel (channel 10, MIDI key 36 = kick, 38 = snare, 42 = closed hat, 49 = crash).
