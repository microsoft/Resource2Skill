### 1. High-level Skill Pattern Extraction

> **Skill Name**: Interactive Sales Dashboard

*   **Tier**: archetype
*   **Core Mechanism**: This skill constructs a multi-sheet, interactive Excel dashboard for sales performance tracking. It leverages Excel Tables for raw data management, PivotTables for data aggregation and analysis, and PivotCharts for dynamic visualizations. Key Performance Indicators (KPIs) are displayed prominently using linked shapes and icons, and a Slicer enables interactive data exploration across all visuals. The reusable pattern involves setting up a structured data source, building analysis objects on a hidden sheet, and presenting insights on a highly formatted, interactive dashboard canvas.
*   **Applicability**: This skill is ideal for creating monthly, quarterly, or annual performance dashboards for sales teams, marketing campaigns, or any scenario requiring interactive tracking of key metrics over time and across different dimensions (e.g., individual agents). It's suitable for datasets with clear categorical and numerical fields where trends and comparisons are crucial. Constraints include needing well-structured, tabular data that can be consistently refreshed.

### 2. Structural Breakdown

-   **Data Layout**:
    *   **Data Sheet**: Flat, tabular data organized into an Excel Table (named "SalesData"). Columns include `Name`, `Date`, `Total Calls`, `Calls Reached`, `Average Duration (sec)`, `Deals Closed`, `Call Conversion Rate (%)`, `Deal Value ($)`, `Call Drop Rate (%)`. New data is appended directly to the table.
    *   **Analysis Sheet (Hidden)**: Houses multiple PivotTables deriving from "SalesData."
        *   A summary PivotTable provides overall KPI values (Total Calls, Calls Reached, Deals Closed, Deal Value) in a single column.
        *   Separate PivotTables are created for each chart, grouping data by `Months (Date)` and summarizing relevant metrics (e.g., Sum of Calls Reached, Sum of Deals Closed, Sum of Deal Value, Average of Average Duration, Average of Call Drop Rate).
        *   A single-cell PivotTable captures the currently selected `Name` from the Slicer for conditional formatting.
-   **Formula Logic**:
    *   **KPI Text Boxes**: Linked directly to specific cells on the `Analysis` sheet containing the aggregated PivotTable values (e.g., `=Analysis!B4`).
    *   **Conditional Formatting (Sales Agent KPIs Table)**: Uses a formula-based rule to highlight the selected salesperson's row based on the Slicer's current selection. Formula example: `=$D10=Analysis!$A$11` (where D10 is the first agent's name in the table, and Analysis!A11 holds the selected agent's name from the slicer).
-   **Visual Design**:
    *   **Theme**: "Aspect" theme is applied for a cohesive color palette.
    *   **Dashboard Background**: Top section (rows 1-8) filled with the primary purple theme color. Lower section (rows 9-40) filled with a custom lighter shade of purple (`#F2EFF5`).
    *   **Titles**: Main title "Sales Dashboard" (Font: Aptos Narrow, 36pt, White). Subtitle "Evaluating Sales Agent Performance" (Font: Aptos Narrow, 16pt, Yellow).
    *   **KPI Cards**: Use rounded rectangle shapes (gold for the left bar, white for the main body) with no outlines and outer shadows. Icons (phone, people, ribbon, money) are inserted and colored with the primary purple theme. KPI values (32pt, purple) and labels (18pt, purple) are placed in separate text boxes over the white shape, centered, with no fill or outline.
    *   **Slicer**: Formatted with the dark purple theme style, with adjusted button heights to remove scrollbars for better visibility of all items.
    *   **Charts**: All charts (column, stacked column, area) have no fill, no outlines, outer shadows, and vertical axes set to a fixed minimum of 0. Gridlines and field buttons are hidden. Data labels are added where appropriate.
    *   **Sales Agent KPIs Table**: Uses a dark purple PivotTable style. Data bars are applied with custom colors (yellow, light purple, purple) to `Total Calls`, `Calls Reached`, `Deals Closed`, and `Deal Value` columns, respectively, using solid or gradient fills and no borders.
-   **Charts/Tables**:
    *   **Sales Agent KPIs Table**: PivotTable, placed on the dashboard, displaying `Name` in rows and `Total Calls`, `Calls Reached`, `Deals Closed`, `Deal Value` in values. Conditional formatting data bars.
    *   **Sum of Calls Reached + Deals Closed**: 2D Stacked Column PivotChart. Data from `Calls Reached` (yellow) and `Deals Closed` (purple). Series overlap 100%, gap width 50%. Data labels (Inside End).
    *   **Total Sales $**: 2D Column PivotChart. Data from `Deal Value` (purple). Gap width 50%. Includes a yellow dashed trendline.
    *   **Average Call Duration (seconds)**: 2D Column PivotChart. Data from `Average Duration` (yellow). Gap width 50%.
    *   **Average Call Drop Rate %**: 2D Area PivotChart. Data from `Call Drop Rate` (gradient yellow to white).
-   **Theme Hooks**: `header_bg` (dark purple), `soft_bg` (light purple), `text_light` (white), `text_accent` (yellow), `text_dark` (purple), `accent_primary` (gold/yellow), `accent_secondary` (purple shades).
