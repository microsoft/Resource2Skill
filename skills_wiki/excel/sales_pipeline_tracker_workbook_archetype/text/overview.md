# Sales Pipeline Tracker Workbook Archetype

Builds a B2B SaaS pipeline workbook with `Deals`, `Reps`, `Accounts`,
`Forecast`, and `Activity Heatmap`. The mechanism uses stage-probability
mapping, formula-backed weighted pipeline rollups, quota attainment flags, and
conditional-format activity density.

Use this for sales operations, forecast review, ARR pipeline, quota attainment,
and rep-activity analysis briefs.
