# Quarterly P&L Template

Three-sheet workbook (Summary, Details, Charts) demonstrating a quarterly profit-and-loss layout: KPI header band, line-item table with Excel SUM formulas, and a side-by-side bar chart comparing Q1-Q4. Suitable as a structural reference for `apply_component` cells targeting `quarterly_report` archetypes.

## Layout
- **Summary** — 4-row KPI band (Revenue, COGS, Gross Profit, Net Income) with absolute values and YoY %
- **Details** — line items × quarters matrix with totals row
- **Charts** — embedded BarChart referencing Details!B2:E12

## Suggested use
Clone this layout when the agent needs a tidy P&L without inventing column structure from scratch.
