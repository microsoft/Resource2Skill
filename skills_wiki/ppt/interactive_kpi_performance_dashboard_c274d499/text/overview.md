# Interactive KPI Performance Dashboard

## Analysis

### 1. High-level Design Pattern Extraction

> **Skill Name**: Interactive KPI Performance Dashboard

*   **Core Visual Mechanism**: The defining visual idea is a dynamic, interactive dashboard that visualizes employee or department performance against targets. It uses form controls (radio buttons for department, dropdown for employee, scroll bar for year) to update a central data table and a corresponding combination chart (clustered column + line). The design is functional and clean, with clear separation between controls, a data table for context, and the primary visualization.

*   **Why Use This Skill (Rationale)**: This is a classic business intelligence pattern. It's effective because it consolidates complex, time-series data into a single, interactive view. Users can self-serve by filtering and drilling down to specific data points (e.g., "How did Employee X in the Finance department perform in 2017?"), making data exploration intuitive and fast. The visual contrast between the actual performance (bars) and the target (line) makes it easy to instantly identify successes and shortfalls.

*   **Overall Applicability**: This style is highly applicable for any scenario involving performance tracking against benchmarks over time.
    *   **Sales**: Tracking individual or regional sales figures against monthly/quarterly targets.
    *   **HR**: Visualizing employee performance review scores or KPI attainment over several years.
    *   **Operations**: Monitoring production output, quality metrics, or efficiency KPIs against operational goals.
    *   **Project Management**: Displaying task completion rates or budget adherence for different teams or project phases.

*   **Value Addition**: It transforms a static, multi-page report into a dynamic, single-slide analytics tool. It empowers the audience to ask and answer their own questions in real-time during a presentation, fostering engagement and deeper understanding of the underlying data.

### 2. Visual Breakdown

*   **Step A: Core Visual Elements**
    - **Controls Area**: A distinct panel, often at the top or side, containing interactive elements for filtering the data.
        - **Radio Buttons**: For high-level categories like Department (Finance, Operation, HR).
        - **Dropdown Menu (Combo Box)**: For selecting a specific item within a category, like an Employee's name.
        - **Scroll Bar**: For navigating a continuous dimension, typically a time series like years.
    - **Visualization Area**: A prominent combination chart is the centerpiece.
        - **Clustered Column Chart**: Represents the actual, measured performance for each period.
        - **Line Chart**: Overlaid on the bars, this represents the target or benchmark for comparison.
    - **Color Logic**: The palette is typically professional and high-contrast to ensure readability.
        - Control Panel Background: A distinct but non-distracting color, like a corporate blue `(79, 129, 189, 255)`.
        - Control Highlights: An accent color for selected items, like yellow `(255, 192, 0, 255)`.
        - Actuals (Bars): A strong, primary color like blue `(79, 129, 189, 255)`.
        - Target (Line): A contrasting, often alert-oriented color like red or orange `(192, 80, 77, 255)`.
    - **Text Hierarchy**:
        - **Dashboard Title**: Large, bold font.
        - **Control Labels**: Clear, uppercase labels (e.g., "EMPLOYEE NAME").
        - **Chart Title**: Dynamic, updating based on the filter selection (e.g., "Performance Review: [Employee Name]").

*   **Step B: Compositional Style**
    - **Layout**: A structured, grid-based layout is essential. The video demonstrates a primary visualization area with controls grouped logically nearby.
    - **Spatial Feel**: The style feels functional, organized, and data-driven. Ample white space (or a neutral background) is used to prevent the slide from feeling cluttered and to draw focus to the chart.
    - **Proportions**: Controls are typically grouped in a header or sidebar, occupying roughly 20-25% of the slide area, leaving the majority of the space for the primary chart.

*   **Step C: Dynamic Effects & Transitions**
    - The key "dynamic effect" is the data in the chart and table updating instantly in response to user interaction with the form controls.
    - **Limitation**: This live interactivity is a feature of the Excel application environment. It **cannot be reproduced** in a static PowerPoint file generated by Python. The code below will simulate the *result* of an interaction by generating a slide that shows the dashboard in a specific filtered state.

### 3. Reproduction Code

#### 3a. Implementation Method Selection

| Aspect of the effect | Method | Why this method |
|---|---|---|
| Dashboard Layout & Shapes | `python-pptx` | Ideal for placing the background rectangles, text boxes, and structuring the slide. |
| Data Visualization (Combo Chart) | `matplotlib` | `python-pptx`'s native chart capabilities are cumbersome for creating styled combination charts. `matplotlib` offers precise control over plotting, labeling, and styling, which can then be inserted as a high-quality, transparent image. |
| Data Handling & Filtering | `pandas` & `numpy` | The tutorial is based on structured data. `pandas` is the standard for creating and filtering the dataframes that will feed the chart, and `numpy` is useful for generating realistic mock data. |
| Interactive Controls | **Not Reproducible** (Simulated Visually) | `python-pptx` cannot create live, data-linked form controls. We will use `python-pptx` shapes and text boxes to create a *visual representation* of the selected filters, making the static slide appear as if it's a snapshot from the live dashboard. |

> **Feasibility Assessment**: **70%**. This code reproduces the complete visual aesthetic of the dashboard for a given set of filters: the layout, color scheme, combination chart, and dynamic titles. The core *interactivity* of the Excel form controls is not reproducible in a generated PPTX. The output is a high-fidelity static snapshot of the dynamic dashboard.

#### 3b. Complete Reproduction Code

```python
import pandas as pd
import numpy as np
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.shapes import MSO_SHAPE
import matplotlib.pyplot as plt
import io

def generate_mock_data():
    """Generates a sample DataFrame mimicking the video's data structure."""
    years = range(2014, 2025)
    departments = {
        "Finance": ["Suja Mohanty", "Suraj Rajput", "Pramod Bhavsar", "Satsh Ojha", "Sintu Kumar"],
        "Operation": ["Harivansh Gautam", "Vini Saini", "Anand Singh Rajput", "Jaishri Saxena", "Virender Sroha"],
        "HR": ["Ekanshika Kalra", "Hemant Gusain", "Sarthak Bhagu", "Gopala Krishna", "Puran Singh"]
    }
    
    data = []
    for dept, employees in departments.items():
        for emp in employees:
            for year in years:
                sales = np.random.randint(200, 950)
                # Ensure target is reasonably close to sales
                target = int(sales * (1 + np.random.uniform(-0.15, 0.25)))
                data.append([dept, emp, year, sales, target])
    
    df = pd.DataFrame(data, columns=["Department", "Employee", "Year", "Sales", "Target"])
    return df

def create_slide(
    output_pptx_path: str,
    department: str = "Finance",
    employee_name: str = "Pramod Bhavsar",
    start_year: int = 2014,
    num_years_to_show: int = 7,
    **kwargs,
) -> str:
    """
    Creates a PPTX slide reproducing the KPI Performance Tracker dashboard.
    
    Note: The interactivity of Excel form controls is simulated. The output is a
    static slide representing the dashboard state for the given parameters.

    Returns: path to the saved PPTX file.
    """
    prs = Presentation()
    prs.slide_width = Inches(13.333)
    prs.slide_height = Inches(7.5)
    slide = prs.slides.add_slide(prs.slide_layouts[6])

    # === Layer 1: Background & Layout Shapes ===
    background = slide.background
    fill = background.fill
    fill.solid()
    fill.fore_color.rgb = RGBColor(255, 255, 255)

    # Header/Control panel background shape
    header_shape = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, Inches(0.5), Inches(0.4), Inches(12.333), Inches(1.5))
    header_fill = header_shape.fill
    header_fill.solid()
    header_fill.fore_color.rgb = RGBColor(70, 114, 196) # A professional blue
    header_shape.line.fill.background()

    # === Data Preparation (Simulating control selection) ===
    df = generate_mock_data()
    
    # Filter data for the selected employee and year range
    end_year = start_year + num_years_to_show - 1
    employee_data = df[
        (df['Employee'] == employee_name) &
        (df['Department'] == department) &
        (df['Year'].between(start_year, end_year))
    ].copy()

    # === Simulate Controls Visuals ===
    # Department selection visual
    for i, dept_name in enumerate(["Finance", "Operation", "HR"]):
        is_selected = (dept_name == department)
        box_color = RGBColor(0, 176, 80) if is_selected else RGBColor(146, 208, 80)
        
        box = slide.shapes.add_shape(MSO_SHAPE.ROUNDED_RECTANGLE, Inches(1 + i * 2.5), Inches(0.6), Inches(2.2), Inches(0.6))
        box.fill.solid()
        box.fill.fore_color.rgb = box_color
        box.text = dept_name.upper()
        box.text_frame.paragraphs[0].font.bold = True
        box.text_frame.paragraphs[0].font.color.rgb = RGBColor(255, 255, 255)
        box.line.fill.background()

    # Employee selection visual
    emp_label = slide.shapes.add_textbox(Inches(1), Inches(1.3), Inches(2), Inches(0.5))
    emp_label.text_frame.text = "EMPLOYEE NAME"
    p = emp_label.text_frame.paragraphs[0]
    p.font.color.rgb = RGBColor(255, 255, 255)
    p.font.bold = True

    selected_emp_box = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, Inches(3.5), Inches(1.25), Inches(4), Inches(0.5))
    selected_emp_box.fill.solid()
    selected_emp_box.fill.fore_color.rgb = RGBColor(220, 230, 241)
    selected_emp_box.text = employee_name
    p = selected_emp_box.text_frame.paragraphs[0]
    p.font.size = Pt(16)
    p.font.color.rgb = RGBColor(0, 0, 0)

    # === Layer 2: Chart Generation (matplotlib) ===
    fig, ax = plt.subplots(figsize=(12, 4.5))
    fig.patch.set_alpha(0.0)
    ax.patch.set_alpha(0.0)
    
    bar_width = 0.4
    index = np.arange(len(employee_data['Year']))
    
    # Bar for Sales
    bars = ax.bar(index, employee_data['Sales'], bar_width, label=employee_name, color='#4F81BD')
    # Line for Target
    line = ax.plot(index, employee_data['Target'], label='Target', color='#C0504D', marker='o', linewidth=2.5)
    
    ax.set_title(f"Employee-wise Revenue: {employee_name}", fontsize=18, weight='bold', pad=20)
    ax.set_ylabel('Revenue', fontsize=12)
    ax.set_xticks(index)
    ax.set_xticklabels(employee_data['Year'])
    ax.tick_params(axis='x', colors='grey')
    ax.tick_params(axis='y', colors='grey')
    
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)
    ax.spines['left'].set_color('grey')
    ax.spines['bottom'].set_color('grey')
    ax.yaxis.grid(True, linestyle='--', which='major', color='grey', alpha=.25)

    for bar in bars:
        yval = bar.get_height()
        ax.text(bar.get_x() + bar.get_width()/2.0, yval, int(yval), ha='center', va='bottom', fontsize=9, color='white', weight='bold')

    ax.legend(frameon=False)
    plt.tight_layout()
    
    img_stream = io.BytesIO()
    plt.savefig(img_stream, format='png', dpi=300, transparent=True)
    img_stream.seek(0)
    plt.close(fig)

    slide.shapes.add_picture(img_stream, Inches(0.6), Inches(2.2), width=Inches(12.1))

    prs.save(output_pptx_path)
    return output_pptx_path

```
