# Dynamic KPI Slicer Dashboard

## Analysis

### 1. High-level Design Pattern Extraction

> **Skill Name**: Dynamic KPI Slicer Dashboard

*   **Core Visual Mechanism**: This technique uses a slicer not to filter data categories, but to select which *measure* (KPI) is displayed in a chart. A disconnected table holds the names of the KPIs, which populates the slicer. A master DAX measure uses a `SWITCH` function to read the slicer's selection and dynamically calculate the corresponding result (e.g., total sales, order count, or product count). The chart's value is then tied to this single, flexible master measure.

*   **Why Use This Skill (Rationale)**: This skill provides high information density and interactivity. Instead of creating multiple slides or charts for different KPIs, it consolidates them into a single, user-driven visual. This empowers the audience to explore the data on their own terms, transforming a static presentation into an interactive analysis tool.

*   **Overall Applicability**: Ideal for business intelligence dashboards, performance reviews, and executive summaries where viewers need to compare different metrics across the same set of categories (e.g., sales by region, orders by company, units by product).

*   **Value Addition**: It dramatically reduces slide clutter and increases audience engagement. It shifts the focus from a fixed narrative to a flexible, exploratory data experience.

### 2. Visual Breakdown

*   **Step A: Core Visual Elements**
    -   **PivotChart**: A standard column or bar chart that displays the data.
        -   *Visual Style*: Clean, minimalist. Gridlines and the value axis are removed to emphasize the data labels on the bars.
    -   **Slicer**: A horizontal slicer, styled to look like a set of tabs or buttons, positioned above the chart.
        -   *Color Logic*: The slicer uses a neutral color for unselected items and a contrasting accent color for the selected item. The chart bars often use a solid, professional color like a medium blue or gray.
        -   *Example Colors*:
            -   Chart Bars: Medium Gray `(128, 128, 128, 255)`
            -   Slicer Background (Unselected): Light Gray `(240, 240, 240, 255)`
            -   Slicer Accent (Selected): Yellow `(255, 192, 0, 255)`
    -   **Data Labels**: Placed on top of each bar to show the precise value, making the value axis redundant.

*   **Step B: Compositional Style**
    -   **Layout**: The slicer acts as a header or control panel for the chart directly below it. This creates a clear cause-and-effect relationship for the user.
    -   **Hierarchy**: The slicer is the primary interactive element. The chart is the secondary, responsive element. The data labels provide the tertiary level of detail.
    -   **Data Structure (The "Secret")**: The core of this technique is not visual but structural. It relies on a Power Pivot data model where the slicer is based on a disconnected table of KPI names, and DAX measures perform the dynamic calculation.

*   **Step C: Dynamic Effects & Transitions**
    -   The primary effect is the real-time update of the chart's bars when a new KPI is selected in the slicer. The bar heights, data labels, and sorting order all change instantly.

### 3. Reproduction Code

#### 3a. Implementation Method Selection

The interactive nature of this dashboard relies on Excel's Power Pivot and DAX engine, which cannot be embedded or executed within a static PowerPoint file generated by Python. The code below will reproduce a **static snapshot** of the dashboard's visual appearance for a single selected KPI.

| Aspect of the effect                 | Method          | Why this method                                                                                                                                                                                            |
| ------------------------------------ | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Data Aggregation (Simulating DAX)    | pandas          | Pandas provides powerful `groupby` and `agg` functions to pre-calculate the KPI values that DAX would compute live. This is the most effective way to prepare the data for a static chart.                 |
| Bar Chart and Basic Layout           | `python-pptx`   | `python-pptx` is the standard for creating charts, shapes, and text boxes and arranging them on a slide.                                                                                                   |
| Slicer Visuals (Non-functional)      | `python-pptx`   | We can easily draw and style shapes (rounded rectangles) with text to perfectly mimic the appearance of the slicer buttons, even though they won't be clickable in the final `.pptx` file.                  |
| Interactivity (Live KPI Switching)   | **Not Possible**| Static file formats like `.pptx` do not have an embedded calculation engine like Excel. This core feature cannot be reproduced with Python code that generates a presentation file.                       |

> **Feasibility Assessment**: **40%**. The code successfully reproduces the visual layout, color scheme, and data representation for a *single, static state* of the dashboard. However, it cannot reproduce the core interactive mechanism of switching KPIs, which is the central "trick" of the tutorial.

#### 3b. Complete Reproduction Code

This code simulates the data preparation that would happen in Power Pivot and generates a slide that visually matches the dashboard's appearance for the "Quantity Sold" KPI.

```python
import pandas as pd
from pptx import Presentation
from pptx.chart.data import ChartData
from pptx.enum.chart import XL_CHART_TYPE, XL_TICK_MARK, XL_LEGEND_POSITION, XL_DATA_LABEL_POSITION
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.dml import MSO_THEME_COLOR
from pptx.enum.shapes import MSO_SHAPE

def create_slide(
    output_pptx_path: str,
    title_text: str = "Company Performance",
    **kwargs,
) -> str:
    """
    Creates a PPTX slide that visually reproduces the layout of the Dynamic KPI Slicer Dashboard.
    Note: The slicer is a static visual representation and is not interactive.

    Returns: path to the saved PPTX file.
    """
    prs = Presentation()
    prs.slide_width = Inches(13.333)
    prs.slide_height = Inches(7.5)
    slide = prs.slides.add_slide(prs.slide_layouts[6])

    # === 1. Data Simulation (using pandas to mimic Power Pivot) ===
    # In a real scenario, this data would come from a database or file.
    data = {
        'Company Name': ['Bold Night', 'Urban Right', 'Meta Creations', 'Lucas Basics', 'Pina Lina'] * 4,
        'Product': ['T-Shirt', 'Shorts', 'Case', 'Basics', 'Crop Top'] * 4,
        'Quantity': [800, 700, 300, 400, 200, 850, 690, 330, 310, 240, 850, 690, 315, 265, 250, 850, 690, 315, 265, 250],
        'OrderID': range(20)
    }
    df = pd.DataFrame(data)

    # --- KPI Calculations ---
    # a. Quantity Sold (The one we will display)
    quantity_sold = df.groupby('Company Name')['Quantity'].sum().sort_values(ascending=False)

    # b. Product Count (For reference)
    product_count = df.groupby('Company Name')['Product'].nunique().sort_values(ascending=False)

    # c. Number of Orders (For reference)
    num_orders = df.groupby('Company Name')['OrderID'].count().sort_values(ascending=False)
    
    # We'll use 'quantity_sold' for our static chart
    kpi_data = quantity_sold

    # === 2. Create and Format the Chart ===
    chart_data = ChartData()
    chart_data.categories = kpi_data.index
    chart_data.add_series('KPI', kpi_data.values)

    x, y, cx, cy = Inches(1.5), Inches(2.0), Inches(10), Inches(4.5)
    chart = slide.shapes.add_chart(
        XL_CHART_TYPE.COLUMN_CLUSTERED, x, y, cx, cy, chart_data
    ).chart

    chart.has_legend = False
    
    # Category Axis Formatting
    category_axis = chart.category_axis
    category_axis.major_tick_mark = XL_TICK_MARK.NONE
    category_axis.tick_labels.font.size = Pt(12)
    category_axis.tick_labels.font.bold = True
    
    # Value Axis Formatting (Remove it)
    value_axis = chart.value_axis
    value_axis.has_major_gridlines = False
    value_axis.visible = False

    # Plot Area Formatting
    plot = chart.plots[0]
    plot.has_data_labels = True
    data_labels = plot.data_labels
    data_labels.position = XL_DATA_LABEL_POSITION.OUTSIDE_END
    data_labels.font.size = Pt(11)
    data_labels.number_format = '#,##0'

    # Series Color
    series = chart.series[0]
    series.format.fill.solid()
    series.format.fill.fore_color.rgb = RGBColor(128, 128, 128) # Medium Gray

    # === 3. Create Static Slicer Visuals ===
    slicer_labels = ["Number of Orders", "Product Count", "Quantity Sold"]
    button_width = Inches(2.5)
    button_height = Inches(0.5)
    start_x = Inches(2.9)
    start_y = Inches(1.0)
    
    for i, label in enumerate(slicer_labels):
        x_pos = start_x + (i * (button_width + Inches(0.1)))
        shape = slide.shapes.add_shape(MSO_SHAPE.ROUNDED_RECTANGLE, x_pos, start_y, button_width, button_height)
        
        shape.text = label
        text_frame = shape.text_frame
        p = text_frame.paragraphs[0]
        p.font.size = Pt(14)
        p.font.color.rgb = RGBColor(0,0,0)
        p.alignment = 1  # Center alignment
        
        fill = shape.fill
        fill.solid()
        # Highlight the selected KPI
        if label == "Quantity Sold":
            fill.fore_color.rgb = RGBColor(255, 192, 0) # Yellow accent
        else:
            fill.fore_color.rgb = RGBColor(240, 240, 240) # Light Gray

        line = shape.line
        line.fill.solid()
        line.fill.fore_color.rgb = RGBColor(200, 200, 200)

    prs.save(output_pptx_path)
    return output_pptx_path

```
